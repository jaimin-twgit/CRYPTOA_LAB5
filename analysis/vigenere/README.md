## Description

This assignment implements cryptanalysis of the Vigenere cipher.

The program performs the following steps:

1. Cleans and preprocesses the ciphertext.
2. Uses Kasiski Examination to estimate the key length.
3. Uses Index of Coincidence for additional key length analysis.
4. Divides the ciphertext into groups according to the key length.
5. Performs frequency analysis on each group.
6. Finds the probable key.
7. Decrypts the ciphertext using the recovered key.
8. Re-encrypts the plaintext to verify the result.
